# PROJECT

## Quick commands
- Setup: `npm install`
- Dev: `npm run dev`
- Test: `npm run test`
- Lint: `npm run lint`
- Typecheck: `npm run typecheck`
- Build: `npm run build`
- Full gate: `npm run check`

## Environment
- `PORT` (server): default `4000`
- `CORS_ORIGIN` (server): default `*`
- `VITE_SERVER_URL` (client): server URL override
